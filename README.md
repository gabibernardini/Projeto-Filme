# 🎯Objetivo do projeto:
Criar um site com informações do filme escolhido, como: ano de produção, diretor, duração, classificação, gênero e o país de origem do filme.

# 🛠️Tecnologias utilizadas:
HTML e VScode.

# 🪛Breve descrição da página desenvolvida: 
A página foi estruturada no arquivo `index.html` para apresentar o filme **Enrolados** de forma organizada:
- **Título e capa:** Utilização da tag `<h1>` com o nome do filme e inclusão de uma imagem da animação na pasta `/img`.
- **Ficha Técnica:** Utilização da tag `<h2>` contendo: Ano de produção, Diretor, Duração, Classificação, Gênero e País de origem.
- **Sinopse:** Texto descritivo da trama usando a tag `<p>`.
- **Mais informações:** Link com a tag `<a>` redirecionando para uma página externa com detalhes sobre o filme.
